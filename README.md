# 家計簿カレンダー（スマホアプリ版）

一日ごとの収入・支出をカレンダーに記録して、日・月の合計を自動計算するアプリです。
**データはあなたの端末（ブラウザ）の中だけに保存されます。** サーバーには送られず、他の人からは見えません。

## 入っているファイル

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体 |
| `manifest.webmanifest` | ホーム画面アプリ化の設定 |
| `sw.js` | オフラインで動かすための仕組み |
| `icon-192.png` / `icon-512.png` / `icon-512-maskable.png` / `apple-touch-icon.png` | アプリのアイコン |

**フォルダの中身をまるごと（同じ階層のまま）**置いてください。ファイルを分けてしまうと動きません。

---

## まず試す（PCでローカル確認）

`index.html` をダブルクリックしてブラウザで開けば、すぐ使えます。
※ローカルファイルとして開いた場合、オフライン機能（sw.js）は動きませんが、入力と保存は問題なく動きます。オフライン化は下の公開手順を踏むと有効になります。

---

## スマホで毎日使う：GitHub Pages で公開する手順

GitHub アカウントがある前提です（無料）。

1. GitHub で新しいリポジトリを作る（例：`kakeibo`）。Public でOK。
2. このフォルダの中身（`index.html` など全ファイル）をそのままアップロードする。
   - リポジトリ画面の「Add file」→「Upload files」に、ファイルを全部ドラッグして「Commit changes」。
3. リポジトリの「Settings」→ 左メニュー「Pages」を開く。
4. 「Build and deployment」の Source を **Deploy from a branch** にし、Branch を `main`／フォルダ `/ (root)` にして Save。
5. 1〜2分待つと、`https://あなたのID.github.io/kakeibo/` というURLが表示される。

### スマホのホーム画面に追加する

- **iPhone（Safari）**: 上のURLを開く → 共有ボタン → 「ホーム画面に追加」。
- **Android（Chrome）**: URLを開く → 右上のメニュー → 「アプリをインストール」または「ホーム画面に追加」。

これで普通のアプリのようにアイコンから起動でき、オフラインでも動きます。

---

## 使い方

- カレンダーの日付をタップ → 「支出／収入」を選び、金額・カテゴリ・メモを入れて「追加する」。
- 各日のセルに、その日の支出（赤）・収入（緑）・合計が出ます。
- 上部に月の収入・支出・残高、下にカテゴリ別の月間支出が出ます。
- 「‹ ›」で月移動、「今日」で今月へ。

---

## データについて（大事）

- データは **このブラウザの中だけ** に保存されます。同じURLを別の人が開いても、その人には空のアプリが見えるだけで、あなたの数字は見えません。
- ただし「このブラウザの中だけ」なので、次の場合はデータが消えます／引き継がれません：
  - ブラウザの履歴・サイトデータを消去したとき
  - 別の端末・別のブラウザで開いたとき（端末ごとに別々の保存になります）
- 大事な記録は、定期的にメモなどに控えておくと安心です。
  （複数端末で同期したい場合は、サーバー保存版（Flask + DB など）が必要になります。）

---

## あとから中身を変えたとき

`index.html` などを更新したら、`sw.js` の `CACHE_NAME` の数字（`kakeibo-v1` → `kakeibo-v2`）を上げてからアップロードしてください。古いキャッシュが残らず、更新が反映されます。
